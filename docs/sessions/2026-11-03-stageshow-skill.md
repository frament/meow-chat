# Скилл `stageshow` для UI-иллюстраций

Дата: 2026-11-03
Ветка: `main`.

## Что сделано

Установлен скилл `stageshow` из `benjitaylor/skills`:

```sh
npx skills add benjitaylor/skills --skill stageshow
```

Ставится в **`.agents/skills/`** — там же лежат остальные девять скиллов проекта
(`angular-developer`, `frontend-design`, `go-development` и т.д.), поэтому выбора не
было: CLI сам нашёл OpenCode и положил файлы рядом с существующими.

Появилось два изменения в репозитории:

| что | размер |
|---|---|
| `.agents/skills/stageshow/` | 358 файлов, 3.1 МБ |
| `skills-lock.json` | +6 строк (`source`, `skillPath`, `computedHash`) |

## Что это за скилл

Макетирование «как настоящий продукт»: окна браузера и приложения, дашборды, телефоны,
уведомления, терминалы, bento-сетки, анимация с курсором. React + обычный CSS, статичная
иллюстрация или короткая анимация. Нужен для hero-картинок, карточек фич, иллюстраций
в документации и демо интерфейса.

Внутри: `SKILL.md` (149 строк — правила и порядок работы), `references/` (14 файлов
правил: кадрирование, хореография, ремесло, проверка), `kit/` (React-компоненты),
`examples/` (эталонные работы — их копируют как отправную точку, а не пишут с нуля),
`scripts/` (снять кадр через headless-браузер, проверить раскладку, отрепетировать).

## Проверка перед использованием

CLI предупредил «review skills before use; they run with full agent permissions» —
посмотрел, что внутри:

- файлы текстовые (`tsx`, `css`, `svg`, `md`), бинарников нет, крупнейший файл —
  скрипт 100+ КБ;
- `child_process.spawn` встречается дважды: `scripts/dev.mjs` поднимает локальный
  dev-сервер, `scripts/film.mjs` снимает кадр через headless-браузер. Оба работают с
  локальным адресом, внешних `fetch` в скриптах нет;
- `package.json` без `postinstall` и прочих хуков установки;
- оценки безопасности с https://skills.sh на момент установки: Gen — Safe,
  Snyk — Low Risk, Socket — 1 alert (какой именно, страница не раскрыла).

**Что не проверено:** сам скилл не запускался — ни `npm install`, ни `npm run dev`, ни
`film.mjs`. Доказано только то, что фронтматтер разбирается (скилл появился в списке
доступных агенту) и что в файлах нет исполняемого при установке кода. Первый настоящий
запуск будет первой проверкой.

## Побочная правка

`.gitignore`: `frontend/node_modules/` → `node_modules/`. Скилл приносит свой
`package.json`, и `npm install` внутри него создал бы 200 МБ непроигнорированных файлов
ровно рядом с исходниками.

## Как пользоваться

Скилл включается сам, когда задача про макет или демо интерфейса. Его собственный
playground (`.agents/skills/stageshow`) требует `npm install` — это отдельный шаг, в
репозиторий ничего не добавляет, `node_modules` теперь игнорируется.

Важное ограничение из `SKILL.md`, которое стоит помнить: макет своего же продукта
берёт токены **из кода проекта** (`references/looks.md`), а не из темы редактора, — иначе
получится «похоже на продукт вообще», а не на MeowChat.
